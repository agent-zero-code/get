# Set up Agent Zero Code on a Mac

One line, pasted into Terminal:

    bash <(curl -fsSL https://raw.githubusercontent.com/agent-zero-code/get/main/setup-mac.command)

Move in with the Claude app: download Move-in-to-Agent-Zero-Code.mcpb from Releases (latest), double-click, Install, then say move me in.

The file installs nothing of ours without an invitation from its maker. It fetches what a Mac is missing (Node, jq, GitHub's tool, VS Code, Claude Code) from their makers and checks each one against the maker's own fingerprint. It holds no secret. Read it first if you like: it is the whole of this repository.
